## Bundled in the program

### FFmpeg (GPL-3.0)
The packaged program contains an `ffmpeg` executable, installed through the Python package
**imageio-ffmpeg 0.6.0** (BSD-2-Clause, Copyright (c) 2019-2025 imageio). The executable is a build of
FFmpeg 7.1 ("essentials" build by gyan.dev) configured with `--enable-gpl --enable-version3`, so it is licensed under the
**GNU GPL version 3**; it includes GPL libraries such as x264 and x265. photag uses it to verify compressed videos
(frame count, SSIM) and to make video thumbnails.

- FFmpeg source code (the corresponding source of the build): <https://ffmpeg.org/download.html#get-sources> (release 7.1), build information and
  scripts: <https://www.gyan.dev/ffmpeg/builds/>
- **Written offer:** for at least three years after a photag release that contains this executable, you can request the complete corresponding
  source of its FFmpeg build by opening an issue at <https://github.com/giamat13/photag/issues>.
- FFmpeg license texts: <https://ffmpeg.org/legal.html>

## Downloaded or contacted at run time (not bundled)

- **InsightFace `buffalo_l` model weights** — downloaded on the first face detection. The InsightFace *code* is MIT-licensed, but the pretrained models are
  provided **for non-commercial / research use only** by their authors. This is compatible with a free, non-commercial photag; a commercial
  version would need different models or a license. Verify the current terms at <https://github.com/deepinsight/insightface>.
- **OpenStreetMap map tiles** — shown in the map view, loaded from `tile.openstreetmap.org`. Map data (c) OpenStreetMap contributors, available under the
  Open Database License (ODbL): <https://www.openstreetmap.org/copyright>. The public tile servers have a usage policy
  (<https://operations.osmfoundation.org/policies/tiles/>); a widely distributed build should use its own tile provider.
- **GitHub** — release information and updates are fetched from the project's releases page.
- **AI tagging providers** (OpenAI, Anthropic, Google Gemini, OpenRouter, or any compatible API) — only when the user configures a key and
  starts tagging; thumbnails are sent to the provider the user chose.

## Not bundled, started by the user's choice

- **HandBrake / HandBrakeCLI** (GPL-2.0-or-later) — installed separately by the user; photag only runs the `HandBrakeCLI` executable.
- **VLC** — optional "open in VLC" for formats the built-in player cannot play; only launched if installed.

## Python packages in the program

Generated by `python tools/gen_notices.py` from the packages the build environment has installed (direct dependencies and everything they pull in).
Some wheels carry their own native libraries: for example `opencv-python` includes FFmpeg libraries (LGPL), `pillow-heif` includes libheif / libde265 (LGPL),
`numpy` and `scipy` include OpenBLAS and the GCC runtime. These keep their licenses, which are compatible with GPL-3.0.
