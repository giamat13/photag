# photag 1.6.0

## What is new
- **Light theme.** View → Light Theme switches the panels, toolbar, dialogs and menus to a light look; the photo stage itself (grid, loupe, filmstrip, compare) stays fixed dark, the same way real darkroom/Lightroom-style apps keep photos surrounded by a neutral, non-distracting background regardless of the UI theme. The choice is remembered.
- **Year in Review.** Library → Year in Review... picks a year and plays an automatic slideshow of that year's best photos, month by month (built on the existing quality score). It is also offered once each January, the same way "On This Day" is offered.
- **Advanced EXIF search.** Advanced Search (and smart collections) can now filter by camera model, lens and focal length, in addition to everything already there (people, keywords, dates, ratings, labels, location...).

Your photos, catalog, backups and settings are not touched by an update. Full source and licenses: see LICENSE and THIRD_PARTY_NOTICES.md.
