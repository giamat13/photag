# photag 22.0.0

## Features

- **Linked keywords**: link two keywords ("HP bus" = "Knight bus") with the **=** button above the keyword list: a photo that gets one of them gets the other too, and loses both together (#39).
- **Automatic keywords by time**: the **⏰** button above the keyword list sets rules such as 7 to 17 = "daytime" (a range over midnight works too). Photos taken in those hours get the keyword, new photos too (#40).
- **Score All**: a button next to Rank scores every photo, shows the score on each thumbnail and sorts the list by Quality Score (#48).
- **Rank and Compare in one flow**: in the Rank window click any photo to choose it instead of the best by score, open them all in Compare, and there use "Pick this, reject the others" (#43).
- **Open with the Timeline**: View > "Open with the Timeline" makes the Timeline the view photag starts with, instead of the Grid (#41).
