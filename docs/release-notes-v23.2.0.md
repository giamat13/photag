# photag 23.2.0

## Small features

- **Score new photos with the AI**: in the AI tagging settings, "Who scores new photos automatically" can be the AI (the provider, key and model of AI tagging; a thumbnail of every new photo is sent to the provider) instead of the program's own measurement, which stays the default. While the AI is not set up, or does not answer, the program's own score is used (#48).
- **A collection from a folder**: right-click a folder in the Folders list > "Make a collection from this folder". The collection holds the photos of that folder; the photos stay where they are (#54).
