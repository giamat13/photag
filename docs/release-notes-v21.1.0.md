# photag 21.1.0

## Small features

- Compare can now show more than two photos: the **+** and **−** buttons in the toolbar add or remove photos (up to four at once) (#49).
- In "Your reports and suggestions" you can change the type of a report from "A problem" to "A feature suggestion" and back (#53).

## Fixes

- "Show in Explorer" now brings the Explorer window to the front instead of leaving it behind (#47).
- Typing in the keyword filter no longer throws the cursor to the start of the box ("day" no longer turns into "yad") (#56).
