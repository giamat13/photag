# photag 18.0.0

## Features
- **Report a problem** (Help menu): describe what went wrong and send it to the photag developers as an issue on GitHub. You see exactly what is sent (version, system, the last error messages; folders, your user name, e-mail and IP addresses are removed), and you can leave the technical details out. When the program was built with the report account set up, no GitHub account is needed; otherwise GitHub opens with your report filled in. At most 3 reports an hour.
