# photag 1.4.1

## What is new
- **More file types.** AVIF images (`.avif`, `.avifs`) are now imported, thumbnailed and displayed natively. GoPro RAW files (`.gpr`) are recognized as RAW. Extra video containers that HandBrake can compress — `.wmv`, `.mpg`/`.mpeg`, `.mts`/`.m2ts`, `.ts`, `.flv`, `.m4v` — were already listed as compressible but were not recognized by the importer; they now import and thumbnail correctly.
- **Combined release notes when several updates were skipped.** If you skip one or more versions and then update, the "What's new" window now shows the notes from every version you missed, not just the latest one.

Your photos, catalog, backups and settings are not touched by an update. Full source and licenses: see LICENSE and THIRD_PARTY_NOTICES.md.
