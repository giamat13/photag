# photag 19.0.0

## Features
- **Surprise Me**: a button in the Grid toolbar (and **Shift+R**) opens a random photo from what the list shows right now, never the same one twice in a row. With a filter or a search on, it only picks from those photos. A nice way to find old pictures again.
- **Compare with a synchronized zoom**: in the Compare view the mouse wheel zooms both pictures together and dragging moves both, so you can check the same spot in each one (for example to pick the sharpest shot). The zoom level is shown, and a new pair starts at 100% again.
- **Recent searches**: the text search field remembers your last 10 searches and offers them as you click or type in it.

## Fixes
- After an update, the old photag window could stay open next to the new one. A window of photag that was opened while the program was already running (it is a separate process) now closes by itself when the update replaces the program, and the old program now ends in a way that cannot get stuck on the way out.
