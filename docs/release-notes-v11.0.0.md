# photag 11.0.0

## Picture viewer: "Open with photag" (replaces Windows Photos)
- Right-click a picture > Open with > photag shows it in a fast viewer **without adding it to the library**: zoom, pan, previous/next picture in the folder, rotate, full screen, show in folder, and an optional "Add to library" button.
- Supports JPEG, PNG, GIF, WebP, BMP, TIFF, HEIC/HEIF, AVIF and common RAW files.
- The installer has an "Open with" option; Preferences > Picture viewer switches it on/off (portable version) and opens Windows' Default apps so photag can be chosen for each picture type.
