# photag 26.0.0

## Features

- **One search box for people, year and meaning**: type "Dana 2023 beach" in the usual search box (Any Searchable Field). photag understands the person (a whole name, or one word of it when only one person has it), the year, and every other word; a photo must match all of them. Press Enter and, when the "Search by meaning" model is installed, the words left are also looked for by meaning among that person's photos of that year. Nothing new is sent anywhere.
