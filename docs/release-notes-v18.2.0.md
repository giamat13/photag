# photag 18.2.0

## Small features
- **Search by place** (suggested in #21): Advanced Search has a new place field. Type a city, an address or a country, or coordinates (`32.08, 34.78`), or press the area button and draw a rectangle on the map; the grid then shows only the photos taken there. A city or country uses its whole area, an address a radius you can change. Coordinates and drawn areas work without internet; only the text of a name you type is sent to OpenStreetMap to find it, and only when you press Find.
