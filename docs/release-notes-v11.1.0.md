# photag 11.1.0

## Fixes to "Open with photag"
- **On by default:** photag now adds itself to the "Open with" menu of pictures the first time it starts (current user only, no administrator). Switching it off in Preferences > Picture viewer is remembered.
- **Opens the picture you chose:** after an in-app code update, "Open with photag" opened the main window instead of the picture. The picture is now shown in the viewer (without adding it to the library) also in that case.
