# photag 18.1.0

## Small features
- **Filter by location** (suggested in #21): the library filter's Metadata tab has a new **Location** column. Photos are grouped by their GPS position (to 0.1 degree, about 11 km) with a photo count for each, photos without a position are under "None", and picking a place filters the grid. Nothing is looked up online. For a place you choose on a map, Advanced Search still has "Near a place on the map".
