# photag 1.1.1

## What is new
- **Clearer update on PCs with Smart App Control.** If Windows blocks the downloaded update installer (Smart App Control refuses unsigned programs it does not know), photag now says so, keeps running and opens the folder with the downloaded file so you can start it from there, instead of showing a confusing "file not found" message. Nothing is changed in that case.
