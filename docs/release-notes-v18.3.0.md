# photag 18.3.0

## Small features
- **Location in the Library Filter**: a new **Location** tab next to Text, Attribute and Metadata. Type a city, an address, a country or coordinates, press Find, and the grid shows only the photos taken there; the radius list sets how far around an address or a point to look. Clear (or the None tab) shows everything again.
- An **Advanced Search** button in the Library Filter row opens the advanced search (also Ctrl+Shift+F).
- **Advanced Search now has everything the Library Filter has**: text (any field or file name), flag, rating (at least / at most / exactly), color label, edited, month and orientation.
- **Many more ways to search** in Advanced Search: keywords (any or all of them), with or without keywords, with or without a location, with or without faces, favorites, people, albums, day of the week, time of day (also over midnight), resolution in megapixels, when the photo was added to the library, and quality. Everything can be combined and saved.

## Fixes
- Saved searches for a city, a country or an area drawn on the map now find the right photos (they matched almost nothing before).
- In Advanced Search, a camera or lens button could stay unselected after the window had been opened more than once.
