# photag 15.0.0

## Features
- **A new look.** photag now has its own visual identity: a deep slate-blue frame with a warm amber accent, module tabs in the middle of the top bar, panel titles in small capitals, and rounded picture cards with a small number badge. The photo surfaces (grid background, big picture, edit canvas) stay neutral gray so colours are judged fairly.
- **The "Develop" module is now called "Edit"** (top bar, View menu, keyboard help; the shortcut `D` is unchanged).

## Fixes
- The MSI installer starts faster: Windows used to show "Please wait while Windows configures photag" for minutes without a progress bar; the package now has far fewer components and quicker install settings.

## Small fixes
- Wording: photag is described in its own words everywhere (README, web site, About window). "Lightroom" is only mentioned as a compatibility fact (import from a Lightroom catalog), with the note that Lightroom is a trademark of Adobe and photag is not affiliated with Adobe.
