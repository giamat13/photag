# photag 22.1.0

## Small features

- **Rank and Compare are one screen**: Rank now opens Compare, with the score of every photo, its place in the ranking and the closed eyes, the best photo first and marked. An ordinary Compare shows the scores too. Click a photo to choose it, then "Pick this, reject the others" (#43).
- "Open with the Timeline" is now remembered when photag is closed and opened again (it was forgotten before) (#41).
- Opening photag several times while it is already open no longer puts an old version back: after three such windows the program fell back to an old version and the windows showed `{"detail":"Not Found"}` (#50).
