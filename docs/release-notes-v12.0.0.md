# photag 12.0.0

## Picture viewer ("Open with photag"): more buttons
- **Recycle Bin** — moves the picture you are looking at to the Recycle Bin (asks first; the `Delete` key does the same) and shows the next one.
- **Edit** — brightness, contrast, saturation, black and white and the rotation you set, shown live; "Save a copy" writes a new file next to the original (`name (edited).jpg`) with the camera data and location kept. The original is never changed.
- **Location** — a small map with the place where the picture was taken (needs an internet connection for the map tiles), or a note that it has none.
- **Information (EXIF)** — every EXIF tag of the file (key `I`).

Nothing here adds the picture to the library.
